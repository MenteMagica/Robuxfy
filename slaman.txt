####### PESQUISA POR CONTEÚDO #######

A ideia aqui é ter o total de 10 resultados para a pesquisa, então precisa executar essas queries e vai ser retornado a quantidade de cada item mostrada no limit. Eu gostaria que voltasse para o front na seguinte ordem:

-- artistas
SELECT name, 'artist' AS type
FROM artists
WHERE name LIKE CONCAT('%', ?, '%')
LIMIT 1;

-- músicas
SELECT title, 'music' AS type
FROM musics
WHERE title LIKE CONCAT('%', ?, '%')
LIMIT 4;

-- podcasts
SELECT title, 'podcast' AS type
FROM podcasts
WHERE title LIKE CONCAT('%', ?, '%')
LIMIT 3;

-- álbuns
SELECT name, 'album' AS type
FROM albums
WHERE name LIKE CONCAT('%', ?, '%')
LIMIT 2;



####### PROCEDURES #######
Criei procedimentos no banco de dados para facilitar sua vida. Mas você precisa limpar os dados caso vier com algum problema.

Cria um novo usuário
CALL create_user(user_json)

Estrutura do JSON:
{
  "username": "usuario123",
  "date_of_birth": "1995-08-15",
  "email": "usuario@example.com",
  "password_hash": "hash_da_senha_aqui",
  "profile_picture": { 
    "type": "users_profile",
    "url": "https://exemplo.com/images/profile.png"
  }
}
A foto de perfil pode não vir, isso está tratado dentro do banco, só não mandar profile picture.
